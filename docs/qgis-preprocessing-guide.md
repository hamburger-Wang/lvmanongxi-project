# QGIS 卫星影像预处理说明

本模块把多时相 Sentinel-2 波段影像处理为可供模型训练或推理的时序 HDF5 数据集。它只新增 Qt 桌面端入口，不影响 Web 可视化支线。

## 输入目录

按时相建立子目录，每个时相内需要完整的 6 个波段：

```text
gis_data/input/
  2026-05-01/
    B02.tif
    B03.tif
    B04.tif
    B08.tif
    B11.tif
    B12.tif
  2026-05-11/
    B02.tif
    ...
```

## 处理步骤

1. QGIS/GDAL 将每个波段重投影至统一坐标系、范围和分辨率。
2. 每个时相合成为 6 波段 GeoTIFF，并按 128 x 128 像素切片。
3. 按相同地理位置堆叠所有时相切片，输出 `data.h5`，形状为 `(N, H, W, T, C)`。
4. 同时输出 `label.csv`，记录样本编号、切片行列号和地理坐标。

## 环境要求

- Windows QGIS，安装后应存在 `bin/python-qgis.bat`。
- 可设置环境变量 `QGIS_ROOT` 指向 QGIS 安装目录；未设置时程序会自动探测常见安装路径。
- 项目 Python 需要安装 `h5py` 和 `rasterio` 才能运行第二阶段的数据集打包。

## 与网页的关系

`data.h5` 只包含遥感时序数据，不包含作物真值标签。它应进入模型训练或模型推理服务；模型预测出分类图后，Web API 再把分类图、长势指标和空间位置返回给 Three.js 进行三维展示。

当前 Web 的 CropSupervision 样本入口读取的是含 `/truth` 的研究数据集，仅用于验证展示链路，不能替代真实推理。
